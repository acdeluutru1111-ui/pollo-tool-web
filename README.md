# 🎬 Pollo Tool — Mobile Web

AI Video & Image generation via Pollo mobile API. Mobile-first design.

## Features
- ✏️ **Text to Image** — AI image generation
- 🖼️ **Image to Image** — Edit images with AI
- 🎬 **Image to Video** — Animate images
- 🎞️ **Reference to Video** — Multiple refs as video
- 🕺 **Mimic Motion** — Character motion cloning

## How to Use
1. Get your session token from pollo.ai (DevTools → Cookies)
2. Paste token in the app
3. Select a generation type, upload files, tap Generate
